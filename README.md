<h1 align="center">🕹️ Contrib Arcade</h1>

<p align="center">Turn your GitHub contribution grid into an animated retro game for your profile README.<br>
Six games, real data, one pure SVG with no JavaScript, regenerated by a GitHub Action.</p>

> Every example below is built from [@Emanuel0428](https://github.com/Emanuel0428)'s real contributions and refreshed daily.

## Use it on your profile

1. In your profile repo (`<you>/<you>`), add `.github/workflows/arcade.yml`:

```yaml
name: Contrib Arcade

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: Emanuel0428/contrib-arcade@v1
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/platformer-dark.svg?game=platformer&palette=github-dark
            dist/platformer-light.svg?game=platformer&palette=github-light

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. Run it once from the **Actions** tab, then add this to your `README.md`:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/<you>/<you>/output/platformer-dark.svg">
  <img alt="platformer" src="https://raw.githubusercontent.com/<you>/<you>/output/platformer-light.svg">
</picture>
```

> Already using [Platane/snk](https://github.com/Platane/snk)? Add the arcade step before your existing push step and use the same `dist` folder. `ghaction-github-pages` replaces the whole `output` branch with whatever is in `dist`.

| Option | Values |
| --- | --- |
| `game` | `platformer`, `invaders`, `blocks`, `breakout`, `life`, `rain` |
| `palette` | `github-dark`, `github-light` |

## Run locally

Requires Node 18+. No dependencies.

```bash
GITHUB_TOKEN=$(gh auth token) node src/cli.mjs --user octocat --out "dist/invaders.svg?game=invaders&palette=github-dark"
node src/cli.mjs --demo --out "dist/life.svg?game=life"   # fake data, no token
node test/smoke.mjs
```

## How it works

Each game is simulated once in Node against your contribution calendar. Every event (a jump, a hit, a piece landing) becomes a CSS `@keyframes` stop inside the SVG, so the file loops on its own anywhere an image can be shown. A fixed seed means the same data always produces the same animation.

Adding a game is a single file in `src/games/` that exports `(grid, palette, rand) => svg`.
